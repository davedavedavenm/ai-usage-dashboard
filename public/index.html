How to get the cookie (2 minutes):
1. Open the Token Plan page logged in.
2. Press F12 → Network tab → refresh the page.
3. Click any request to api.json → right-click it → Copy → Copy as cURL (bash).
4. In the copied text find -H 'cookie: …' and copy everything between the quotes.
Do not copy from the Headers pane — DevTools truncates it with a … there and the cookie will be rejected.
5. Paste above → Save. The card updates on the next 10-minute check.

Setup (once):
1. In Telegram, message @BotFather → send /newbot → follow prompts → copy the token.
2. Open a chat with your new bot and send it any message (it cannot message you first).
3. Get your chat ID: open https://api.telegram.org/bot<TOKEN>/getUpdates in a browser → find "chat":{"id":…}.
4. Paste both above → Save → Send test message to confirm.
Notes: secrets are stored only on the server (data/settings.json, never committed), shown masked here, and the dashboard is LAN-only. Claude / ChatGPT / Z.ai / OpenCode Go / Gemini use OAuth logins on the server — see the dashboard card hints or the repo README for the SSH recipe.
